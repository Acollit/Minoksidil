=== Minoksidil — Порядок сортировки товаров ===
Requires at least: 5.6
Requires PHP: 7.0
WC requires at least: 4.0
Stable tag: 1.0.0

Drag-and-drop сортировка товаров WooCommerce с применением порядка на всех витринах.

== Что делает ==

* Добавляет страницу «Товары → Порядок сортировки» с drag-and-drop списком товаров.
  Порядок сохраняется автоматически (AJAX) в поле menu_order каждого товара.
* Фильтры на странице: категория, поиск по названию, кол-во товаров на странице.
* Применяет заданный порядок:
  - в каталоге магазина, архивах категорий/меток и результатах поиска;
  - в шорткодах [products], [product_category] и аналогичных, где не задан свой `orderby`.

== Режимы ==

Настройка на странице плагина — «Применять заданный порядок принудительно»:

* Включено (по умолчанию): сортировка каталога жёстко = «наш порядок»,
  в выпадающем списке сортировки каталога остаётся только этот вариант.
* Выключено: «наш порядок» используется как сортировка по умолчанию,
  но покупатель может выбрать другую сортировку из стандартного списка WooCommerce.

== Важно про блоки Gutenberg ==

Блоки «Товары» / «All Products» (новый редактор) строят список через собственный
запрос и НЕ читают глобальную сортировку каталога. Для них порядок задаётся в самом
блоке: в настройках блока выберите «Сортировать по → Порядок в меню» (Menu order).
Заданный плагином menu_order при этом будет учтён.

== Заметки ==

* Сортировка drag-and-drop работает в пределах одной страницы списка. Чтобы упорядочить
  весь каталог за раз, увеличьте «кол-во на странице».
* Связанные товары, апселлы и кросс-селлы используют отдельную логику WooCommerce
  и плагином намеренно не переопределяются.
