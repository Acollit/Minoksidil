# Инструкция по управлению сайтом minoxidillum.pro

Интернет-магазин средств для роста волос • тема Minoksidil • июль 2026.
PDF-версия: `Инструкция-по-сайту.pdf` в корне проекта.

## 1. Вход в админку и карта разделов

Панель управления: **https://minoxidillum.pro/wp-admin/**

| Что нужно изменить | Где в админке |
|---|---|
| Телефон, e-mail, адрес, соцсети, график работы | Minoksidil → Настройки |
| Тексты и картинки на страницах | Страницы → открыть страницу → поля под редактором |
| Товары, цены, фото товаров | Товары |
| Порядок товаров в каталоге | Товары → Порядок сортировки |
| Фото «до/после», истории клиентов | До/После |
| Статьи блога | Записи |
| Формы (поля, письма, получатель) | Формы (Contact Form 7) |
| Какая форма где выводится | Minoksidil → Настройки → Формы обратной связи |
| Пункты выдачи на карте в корзине | Minoksidil → Пункты выдачи (ПВЗ) |
| Заказы покупателей | WooCommerce → Заказы |

## 2. Настройки темы

Раздел **Minoksidil → Настройки**. После изменений — «Сохранить настройки».

### 2.1. Контакты

| Поле | Где отображается |
|---|---|
| Телефон | Шапка, подвал, страница «Контакты» |
| Email для уведомлений о заказах | Сюда приходят письма о заказах и заявки из форм |
| Email (публичный) | Подвал, страница «Контакты» |
| Адрес | Подвал, страница «Контакты» |
| График работы | Блоки «График работы» на «Контактах» и «Доставке» |

### 2.2. Социальные сети

ВКонтакте, Telegram, Telegram 2, MAX, Avito — полные ссылки (с `https://`).
Иконки выводятся в подвале, на «Контактах» и «Гиде».

### 2.3. Карта на странице «Контакты»

Поле «Карта (iframe)»: Яндекс Карты → «Поделиться» → «Виджет карты» → вставить код `<iframe …>` целиком.

### 2.4. Ссылки в подвале

URL политики конфиденциальности и согласия на обработку данных — используются в подвале и в чекбоксах согласий в формах.

> **Примечание.** Блок «Главная страница» в настройках — устаревший: контент главной редактируется через поля ACF на самой странице (раздел 3). Блок «API-ключи для карт доставки» заполнять не нужно.

## 3. Редактирование контента страниц (поля ACF)

Страницы → открыть страницу → блок полей под редактором → изменить → «Обновить».

### 3.1. Общие правила

- **Пустое поле** = на сайте стандартный текст, заложенный в шаблон. Очистите поле, чтобы вернуть исходник.
- В многострочных полях **Enter даёт перенос строки** на сайте.
- **Повторители (карточки)**: «Добавить карточку»; строки перетаскиваются за номер, удаляются минусом (при наведении). Нет строк = стандартные карточки.
- После сохранения проверяйте страницу с **Ctrl+F5**.

### 3.2. Главная страница

| Поле | Что меняет |
|---|---|
| Hero — заголовок / описание | Первый экран |
| Каталог — заголовок / кнопка | Блок товаров (8 шт. из категории «Лосьоны» автоматически, в порядке сортировки) |
| «Почему мы» — заголовок и карточки | Повторитель: заголовок, картинка, описание |
| Истории восстановления — заголовок / кнопка | Шапка слайдера (слайды — записи «До/После») |
| Статья — заголовок / ссылка / текст | Тёмный блок внизу; ссылка ведёт на блог |

### 3.3. Страница «Гид»

| Поле | Что меняет |
|---|---|
| Hero — заголовок | Первый экран |
| О нас — заголовок и два текста | Две колонки (визуальный редактор) |
| Статьи — заголовок / ссылка | Шапка блока (3 последние записи автоматически) |
| Результаты — заголовок / описание / ссылка | Шапка блока (3 записи «До/После») |
| Сотрудничество и Опт | Блок промокодов и оптовых поставок |

### 3.4. Страница «Контакты»

Баннер — заголовок; Сотрудничество/Опт; CTA — заголовок и текст (рядом форма).
Телефон, почта, адрес, соцсети, график, карта — из настроек темы.

### 3.5. Страница «Доставка и оплата»

| Поле | Что меняет |
|---|---|
| Баннер — заголовок | Баннер |
| Оплата — заголовок / карточки / описание | Карточки оплаты (иконка + текст; пусто = стандартные 3) и текст условий |
| Доставка — заголовок / кнопка / карточки | Карточки: название, логотип, сроки, стоимость, способ получения (пусто = стандартные 7) |
| CTA — заголовок / текст | Блок «Остались вопросы?» с формой |

### 3.6. Страница «До/После»

Заголовок и подзаголовок баннера, подсказка поиска, дисклеймер. Сами результаты — раздел «До/После» (см. п. 5).

### 3.7. «Заявка» и «Заказ» (страницы «спасибо»)

Заголовок, текст, надпись на кнопке.

### 3.8. Политика конфиденциальности

Обычная страница, редактируется в основном редакторе.

## 4. Товары

### 4.1. Добавление

1. Товары → Добавить: название, описание.
2. «Данные товара» → Базовая цена (для акции — «Цена распродажи»).
3. Категория справа. Категория «Лосьоны» (loseny) выводится на главной.
4. Фото — в ACF-галерею **«Картинки»** внизу: первое фото показывается в каталоге и на главной. Если галерея пуста — используется «Изображение товара» WooCommerce.
5. «Опубликовать».

### 4.2. Метка «NEW»

Плашка NEW = галочка **«Рекомендуемый»** (звёздочка в списке товаров).

### 4.3. Порядок товаров

Товары → **Порядок сортировки** — перетащить мышкой, сохранить. Применяется в каталоге и на главной.

### 4.4. Фильтры каталога

Строятся из атрибутов WooCommerce (Товары → Атрибуты): создать атрибут, добавить значения, назначить товарам.

## 5. Результаты «До/После»

Раздел **До/После** в меню админки. Выводятся: слайдер на главной, 3 шт. на «Гиде», все — на странице «До/После» (с поиском).

1. До/После → Добавить результат. Заголовок = имя клиента.
2. «Характеристики результата»:

| Поле | Пример | Примечание |
|---|---|---|
| Имя, возраст | Андрей, 37 лет | Если пусто — берётся заголовок |
| Используемый товар | Миноксидил 5% KIRKLAND | По нему работает поиск |
| Форма | Раствор 5% | Пустые строки скрываются |
| Частота применения | 2 раза в день | |
| Срок применения | 6 месяцев | |
| Результат | 80% восстановления | |
| Период | 6 | Только число (месяцев), для фильтра |

3. Галерея **«Картинки»**: первое фото — обложка, по клику листаются все. Пусто — используется «Изображение записи».

## 6. Статьи (блог)

- Записи → Добавить. Обязательно «Изображение записи» (миниатюра карточки).
- Анонс — поле «Отрывок» (включается в «Настройки экрана»).
- Выводятся: 3 последние на «Гиде», все — на странице блога.

## 7. Формы обратной связи (Contact Form 7)

Плагин Contact Form 7 (раздел **Формы**). Тема автоматически создала:

| Форма | Где выводится |
|---|---|
| Обратный звонок (модальное окно) | Окно «Заказать звонок» в шапке |
| Обратная связь (CTA на страницах) | «Давайте обсудим ваш случай» (Контакты), «Остались вопросы?» (Доставка) |

### 7.1. Редактирование

- Вкладка «Шаблон формы» — поля; вкладка «Письмо» — получатель («Кому»), тема и текст письма.
- Тексты и ссылки согласий — прямо в шаблоне формы.

### 7.2. Привязка к местам вывода

Minoksidil → Настройки → «Формы обратной связи (Contact Form 7)» — два списка (модалка и CTA). «— не выводить —» скрывает форму.

### 7.3. Если письма не приходят

Проверить «Спам»; настроить SMTP (WP Mail SMTP / FluentSMTP с ящиком домена). Касается и писем о заказах.
Если CF7 деактивировать — модалка переключится на встроенную форму темы, CTA-формы скроются.

## 8. Пункты выдачи (ПВЗ)

Minoksidil → Пункты выдачи (ПВЗ):

- **Импорт** CSV/JSON: колонки service (cdek/yandex/ozon), code, name, address, city, lat, lng, work_time, phone.
- **Демо-точки** — тестовые точки (Москва, СПб).
- **Очистка** — удаляет все точки.

## 9. Заказы

- WooCommerce → Заказы. Онлайн-оплаты нет: заказ приходит в статусе «Обработка», менеджер связывается с клиентом.
- Уведомление о заказе — на «Email для уведомлений о заказах».
- Колонка «Тип доставки» (Курьер/ПВЗ); выбранный ПВЗ — в деталях заказа.
- Статусы меняются вручную.

## 10. Меню сайта

Набор ссылок в шапке и подвале фиксированный: Каталог + «До/после», «Гид», «Доставка и оплата», «Контакты». Ссылки привязаны к ярлыкам страниц: `do-posle`, `gid`, `dostavka-i-oplata`, `kontakty`.

> **Не меняйте ярлыки этих страниц** — пункты меню будут вести на несуществующие адреса.

## 11. Важные предостережения

- Не удаляйте служебные страницы: Корзина, Оформление заказа, «Заявка», «Заказ», Политика, страницы меню.
- Не редактируйте файлы темы через «Внешний вид → Редактор файлов темы».
- Не деактивируйте плагины: WooCommerce, ACF, Contact Form 7, «Порядок сортировки товаров».
- Перед обновлениями плагинов — резервная копия средствами хостинга.
- Картинки загружайте оптимизированными (WebP/JPEG, до ~300 КБ).
